| Papel | Route here when |
|---|---|
| `rapido` | The change is mechanical and bounded, with no design decision: a typo, a rename, a config value, a one-line fix whose location you already know. |
| `visual` | The result of the change is something a person sees: UI, styling, layout, animation, copy placement. |
| `profundo` | Default for implementation: the change requires understanding the code before touching it. |
| `estelar` | Escalation only: `profundo` failed or came back with doubts, `oracle` rated the task hard, or correctness depends on invariants. |
| `prosa` | The deliverable is text for people: docs, READMEs, release notes, messages. |
